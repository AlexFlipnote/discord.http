play(audio, *, after=None) → None¶

Play an audio source over the connection.

A string is handed to ffmpeg as its input, and ffmpeg opens whatever it names: local files, HTTP(S) and every other protocol it was built with. Do not pass text a user typed without checking it first, otherwise they can make the machine the bot runs on read its own files or reach hosts only it can see. ffmpeg can be limited to a set of protocols with before_options="-protocol_whitelist http,https,tcp,tls,crypto" on FFmpegOpusAudio or FFmpegPCMAudio.

Parameters:

  • after (Callable[[Exception | None], object] | None) – A callback invoked with any error once playback finishes, it can also be async def.

class discord_http.voice.sinks.WaveSink(destination)¶

Bases: AudioSink

Audio sink that writes received PCM to a single 48kHz 16-bit stereo WAV file.

Audio from all speakers is appended to the one stream in arrival order; it is not mixed. With a single speaker this produces a normal recording, but simultaneous speakers will have their chunks interleaved back-to-back and sound garbled. To handle overlapping speakers, separate the audio per user first (for example with a CallbackSink that routes each user to its own file) and mix the results afterwards.
